# Материалы для внешнего аудита

- **`BRIEF.md`** — задание: контекст компании и рынка, референс, действующие
  дизайн-правила, что проверять и в каком формате отвечать. Читать первым.
- **`REFERENCE-OCTOPUS.md`** — разбор структуры сайта-референса octopus.energy:
  порядок блоков на каждой странице, повторяющиеся приёмы, сопоставление с
  нашими страницами. Нужен, если у тебя нет браузера.
- **`screens/`** — полностраничные скриншоты всех страниц сайта: каждая в двух
  видах, `-desktop.jpg` (1440 px) и `-mobile.jpg` (390 px). Сняты с локальной
  сборки; код показывает структуру, скриншоты — как это выглядит.

Список страниц на скриншотах: `home`, `heat-pumps`, `solar`, `to-know`,
`to-know-what-is-a-heat-pump`, `to-know-grid-or-hybrid`, `calculator`,
`catalog`, `catalog-product`, `about`, `projects`, `privacy`.
